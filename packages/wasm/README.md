# WASM package

This package owns Rust/WASM loading, typed wrappers, and runtime-specific instantiation details.

The current release ships the transcript-core command contract around the Rust crate. It verifies canonical objects, fixture replays, chunk roots, reserved protocol hash derivation, `GF(65537)` interpolation/comparison checks, development passive BGV setup package verification, the initial accepted collective BGV setup verifier gate with carry-aware VSS relation profile binding, BDLOP/LNP-style setup commitment profile binding, root-bound review-gated setup commitment security certificate verification, setup-proof profile and challenge-domain binding, fixed `d = 128`, `omega = 2` LNP tbox challenge layout metadata, strict LaZer-style tbox proof-byte decoding with retained decoded transcript fields for the setup-proof profile, full-profile public VSS material size accounting, root-bound setup transport certificate and chunk-manifest verification, accepted HE security certificate verification for current `Q_data`/`Q_share` direct evaluator replay exposure with explicit `Q_target` refusal, transported binary public VSS material derivation for threshold-share commitments, ML-DSA-65 phase signed-root verification, common-randomness commit/reveal binding, accepted public-derivation binding, deterministic setup public-matrix coefficient sample binding for commitment and setup-proof matrices, root-bound VSS coefficient commitment record verification, root-bound public VSS coefficient commitment material verification with profile-ring enforcement, root-bound private VSS envelope commitment-set verification with mailbox AAD, recipient mailbox public-key bytes-hash binding, and hashed encrypted-envelope object binding, root-bound signed VSS share acceptance verification, signed VSS complaint abort verification, local private VSS share envelope aggregate-opening verification with AAD-hash binding and leaked-coefficient refusal, accepted-package threshold-share commitment recomputation from full public VSS coefficient commitment material, root-bound same-secret statement and proof-family binding verification, optional internal same-secret relation proof verification with claim-pending status, fixed setup-proof profile/challenge-domain/sampler record binding, root-bound transported same-secret proof material, and fixed verifier-side response bounds over embedded or transported public VSS material, root-bound public-key share/proof statement verification, optional internal public-key share proof verification that binds the verified same-secret proof-set and per-trustee proof roots while keeping claim-pending lifted no-wrap relation status and fixed verifier-side response bounds over embedded public share material, claim-pending collective public-key aggregate verification from internal proof-bearing shares with same-secret proof-set binding, premature raw or root-only collective public-key material refusal, frozen evaluator-key schedule verification with premature evaluation-key material refusal, roots-only local trustee setup state commitment verification, neutral accepted-setup command error mapping, the internal direct encrypted ballot command, stable canonical rejection codes, and explicit WASM kernel integrity expectations in Node and browser/WASM builds.

The WASM package is not a public voting API. Raw BGV operations, proof witnesses, encryption randomness, plaintext oracle helpers, evaluator intermediate openings, raw VSS shares, setup secrets, and decryption helpers remain internal. The passive setup command is development evidence only and cannot close `CollectiveBgvSetup-v1`.
