<section class="landing-section not-content">
  <div class="landing-section__header">
    <h2>Use the package</h2>
    <p>
      Start with installation and the public root import. Reserved complete
      protocol entry points fail closed until the matching protocol layer exists.
    </p>
  </div>

  <div class="landing-steps-shell">
    <Steps>
      1. **Install the package.**
         Use `npm install sealed-lattice` or `pnpm add sealed-lattice`.
      2. **Import from the root.**
         Use `sealed-lattice` for the supported public API.
      3. **Verify structured evidence.**
         Pass poll, board, roster, transcript, receipt, or proof records to the matching verification helper.
      4. **Keep the current limits explicit.**
         Ballot generation, casting, aggregation, tally evaluation, and production decryption are not available yet.
    </Steps>
  </div>
</section>
