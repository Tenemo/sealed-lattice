<section class="landing-section not-content">
  <div class="landing-section__header">
    <h2>Selected direction</h2>
    <p>
      The active construction is a mobile-browser-first voting workflow where
      each roster participant also acts as a trustee. Untrusted services may
      store transcript objects, but participant clients must verify the ceremony
      locally.
    </p>
  </div>

  <div class="landing-split-grid">
    <Card title="Direct encrypted ballot path">
      <div class="landing-card-copy">
        <p>
          Each voter publishes one encrypted ballot. Verification must check
          setup evidence, ballot validity, first-valid ballot selection, public
          aggregation, replayed evaluation, finality, target-bound decryption,
          and decoded result checks.
        </p>
        <p>
          No trusted tally server, special verifier, heavy external prover, or
          desktop-class auditor is part of the intended verification path.
        </p>
      </div>
    </Card>

    <Card title="Current limits">
      <div class="landing-card-copy">
        <p>
          The current package is for development verification and integration
          work. The complete public voting API is not available yet.
        </p>
        <p>
          The security guide points to the canonical threat model, retry
          policy, audit statement, and cryptographic caveats.
        </p>
      </div>
    </Card>

  </div>
</section>

    <p>
      Start with installation and the public root import. Complete voting
      entry points remain unavailable until the complete workflow is implemented and
      verified.
    </p>
  </div>

  <div class="landing-steps-shell">
    <Steps>
      1. **Install the package.**
         Use `npm install sealed-lattice` or `pnpm add sealed-lattice`.
      2. **Import from the root.**
         Use `sealed-lattice` for the supported public API.
      3. **Verify current public evidence.**
         Use the current helpers for development verification and package integration.
      4. **Keep the current limits explicit.**
         Setup, ballot generation, casting, aggregation, evaluator replay, target-bound decryption, and result release are not complete public APIs yet.
    </Steps>
