<section class="landing-section not-content">
  <div class="landing-section__header">
    <h2>Follow the current boundary</h2>
    <p>
      The supported path is short and explicit while the real protocol work is
      still incomplete.
    </p>
  </div>

  <div class="landing-steps-shell">
    <Steps>
      1. **Install the public package name.**
         Use `sealed-lattice` as the only supported public import path.
      2. **Use the safe public helpers.**
         The package exposes safe fixture verification, election foundation helpers, receiver-key proof verification, and ballot proof-record verification. Scoped relation package acceptance stays fail-closed until verifier-derived lowering and trusted public randomness checks exist.
      3. **Develop inside the workspace packages.**
         Use the private packages for shared types, protocol, crypto, wasm, and testkit work.
      4. **Keep the Rust/WASM path verified.**
         The transcript-core and ballot privacy proof backend must continue to build natively and load in Node and browsers.
    </Steps>
  </div>
</section>
